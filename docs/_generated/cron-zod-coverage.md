## Maintenance

When a new cron route is added:
1. First handler lines must be `const deny = authFailureResponse(verifyCronAuth(request)); if (deny) return deny;`.
2. If it accepts a body, validate it via `parseBody(request, ZodSchema, { allowEmpty: true })`.
3. If it takes no body, add an entry to `ALLOW_NO_PARSEBODY` in `scripts/check-zod-on-mutating-routes.mjs` with a one-line reason, OR add an inline `// lint-allow: no-parsebody — <reason>` comment at the top of the route file.
4. Run `npm run lint:guards` to verify.
