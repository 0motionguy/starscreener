## What the impeccable CLI cannot see

The CLI is a deterministic substring matcher. It catches:

- `borderLeft: ... solid`
- `border-l-N`, `border-s-N`, `border-inline-start: ... solid`
- `bg-black` (incl. with opacity modifiers it can't parse)
- `transition: padding | height | width | margin`

It cannot see:

- `box-shadow: inset` masquerading as a side border
- `shadow-[inset_N_0_0_<color>]` Tailwind arbitrary values
- `clip-path: polygon(...)` triangles
- Logical CSS properties for non-border patterns
- Whether the side-decoration is functional (color-key) or decorative (slop)

This is why the 2026-05-13 recalibration is the authoritative reading: the CLI flags locations to inspect, not verdicts to fix.
