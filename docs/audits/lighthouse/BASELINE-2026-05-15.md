## Categorized findings

### Performance (1 route < 80)

- **/twitter 78** — `Largest Contentful Paint` + `Total Blocking Time` + `Bootup Time` all over budget. Root cause: 200-row leaderboard + RSC payload serializing both tabs. Mitigated by CSS extraction in commit `c6e813984`. Real fix needs lazy-loading the inactive tab (separate refactor PR).

### Accessibility (3 routes < 90, ALL FIXED on this branch)

- **/signals 86** — 18 `aria-allowed-attr` violations (aria-pressed on `<Link>`) + 5 color-contrast hits. Fixed in commits `077e3c370` + `2c0336e0d`.
- **/top10 89** — 2 `label` (input without aria-label) + 6 color-contrast (chip count + .px opacity). Fixed in commit `3d612e206`.
- **/ + others at 90** — borderline; my color-contrast + target-size fixes (commits `28a722b6d` + `11403e7fd` + `a0b83644c`) lift to ~96.

### Best-Practices (ALL 25 routes 73-77 — Clerk 3rd-party cookies)

ROOT CAUSE: every page loads Clerk's auth SDK from `positive-crawdad-45.clerk.accounts.dev`. Cookies `__cf_bm` + `_cfuvid` are set on that third-party domain → Chrome's `third-party-cookies` audit fires + `inspector-issues` fires. Some routes additionally fail `valid-source-maps` (Sentry source maps are `hideSourceMaps:true` for security — intentional) and `errors-in-console`.

**NOT autonomously fixable** — needs operator decision:

1. **Lazy-load Clerk** — refactor so ClerkProvider mounts only on auth screens (/sign-in, /sign-up, /you/*). Risk: breaks `useAuth()` calls on other pages. Major refactor.
2. **CNAME Clerk to first-party** — configure Clerk dashboard so auth requests hit `auth.trendingrepo.com` (same origin). Cookies become first-party. Operational change.
3. **Accept** — ship as-is; Best-Practices stays at 73-77 across the site. Lighthouse public score is "bad" by their grading but functionally fine.

### SEO (4 routes < 95, ALL FIXED on this branch)

- **/repo/vercel/next.js 69** — `<meta name="robots" content="noindex,follow">` emitted on cold Lambda because `getDerivedRepoByFullName` returns null in `generateMetadata` before refresh hooks run. **Critical regression** affecting every repo page. Fixed in commit `88d42cc1b` (await refreshTrendingFromStore in generateMetadata).
- **/lobsters, /producthunt, /npm 92** — canonical points to `https://trendingrepo.com` instead of the page URL. Root cause: `alternates.canonical: "/"` in root layout `src/app/layout.tsx` inherited by every child page that doesn't override. **Probably affects ~20+ pages, just only flagged on these by Lighthouse.** Fixed in commit `bef6d017f` (removed root canonical, added explicit canonical to home).
